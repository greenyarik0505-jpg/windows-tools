# WindowsTools

Безкоштовний «швейцарський ніж» для Windows 11: одна іконка в треї, набір модулів, кожен можна вимкнути.

Мікшер гучності по застосунках · системний монітор · перемикач вікон із прев'ю · снаппінг ·
історія буфера обміну та сніпети · скріншоти й запис екрана · Island · чистилка й деінсталятор ·
піпетка, OCR, keep-awake.

> Статус: фаза 0 — фундамент. Коду застосунку ще немає.
