# ADR 0001: C# + WinUI 3, без Rust

Дата: 2026-11-25. Статус: прийнято.

## Контекст

Потрібен легкий застосунок у треї з глибоким доступом до Win32/WinRT/COM, який паралельно пишуть
4 розробники з AI-агентами. Розглядалися: C# + WinUI 3, Tauri (Rust + web), Electron, гібрид C# + Rust.

## Рішення

C#/.NET 10 + WinUI 3 (Windows App SDK), unpackaged. Win32 — через CsWin32. Rust не додаємо.

## Чому

- Майже вся робота — виклики системних API, а не обчислення; Rust не дає тут виграшу.
- Один тулчейн: простіший CI, дебаг, онбординг і правила для агентів.
- Нативний вигляд Windows 11 і мала памʼять порівняно з Electron.

## Наслідки

- Якщо профайлер покаже вузьке місце, яке не вирішується в C#, нативна бібліотека додається
  за інтерфейсом у `Core` окремим ADR із замірами «до/після».
